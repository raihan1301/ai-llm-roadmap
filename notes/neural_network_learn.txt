Gradient Function

Muliple variable calculus :- Gradient of a function gives you the direction of steepest ascent
length of this gradient vector is how steep the slope is

gradient function give the nudges which can be add up in the vector, which tells the most rapid decrease to the cost function

Note : the cost function is average on all the training data
and how it learn is done through back propogation

process of repeatedly nudging an input of a function by some multiple of negative gradient is called gradient descent
it is a way to converge towards some local minimum of a cost function

so the nudge tells us two important thing. if corresponding of the input vector (gradient) should be nudged dow or right 
if its negative than vector should be decrease, if positive than increase
