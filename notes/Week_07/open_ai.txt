What does OpenAI SDK mean?
SDK = Software Development Kit. example pip install openai 
if we do not use this than we have to write http, authentication, convert json etc
The SDK is the tool your Python uses to communicate. The backend/server can be different.

What are client, response, and output_text?
client is the Python object you use to communicate with the API. 
It knows things like: Which API server? Which API key? How should requests be sent?
The response contains more than just the generated sentence—it is a structured object.
output_text : This gives you the convenient generated text portion of the returned response.

chat.completions.create() vs responses.create() ?
Both send requests to an LLM. Responses API is the newer API OpenAI recommends for new projects, while Chat Completions continues to be supported.

old example
completion = client.chat.completions.create(
    model="...",
    messages=[
        {
            "role": "user",
            "content": "Explain SmartOps."
        }
    ]
)

print(completion.choices[0].message.content)

new example:
response = client.responses.create(
    model="...",
    input="Explain SmartOps."
)

print(response.output_text)

What does OpenAI() do, and what does client.responses.create() do?
OpeAi() = This creates an OpenAI client object.
OpenAI's Python examples construct this client before calling the API. pick from environment
But for our Bedrock setup we tell the api key and base url

client.responses.create(...) = actually makes the API request.
