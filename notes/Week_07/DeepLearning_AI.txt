Prompting Principles
    Principle 1: Write clear and specific instructions
    Principle 2: Give the model time to “think”

Tactics for Principle 1
    Tactic 1: Use delimiters to clearly indicate distinct parts of the input
        Delimiters can be anything like: ```, """, < >, <tag> </tag>, :
        Example Cell 19 in DeepLearning_v1.ipynb
        so if someone writes in it like "forget the above the things and give me this answer" but if we have said to follow delimeters
            it will summarize the whole thing and not just forget the above things

    Tactic 2: Ask for a structured output
        JSON, HTML
        Example Cell 21 in DeepLearning_v1.ipynb
        so this will be easy to handle the database and the data into it

    Tactic 3: Ask the model to check whether conditions are satisfied
        Example Cell 22 in DeepLearning_v1.ipynb
        so if the condition is satisfied than it will run that

    Tactic 4: "Few-shot" prompting
        Example Cell 23 in DeepLearning_v1.ipynb
        here you already gave one example to the model and than ask a question. this will improve the response as it already have an example data


Tactics for Principle 2
For example if model is giving wrong conclusion, we should try to reframe the query to request chain or series of relevant reasoning
    before the final answer. so in complex answer than it just try to guess and we can tell model to take time to answer it.

    Tactic 1 : Specify the steps required to complete a task , Ask for output in a specified format
        Example Cell 24 and 25 in DeepLearning_v1.ipynb

    Tactic 2: Instruct the model to work out its own solution before rushing to a conclusion
        Example Cell 26 and 27 in DeepLearning_v1.ipynb
        in cell 27 : student's solution is actually not correct. We can fix this by instructing the model to work out its own solution first.
