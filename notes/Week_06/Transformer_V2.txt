General Transformer architecture

Encoder (left) : encoder recieves an inout and buidls a representation. meaning model is optimized to acquire understanding from input
Decoder (right) : decoder uses encoder representation(features) along with other inputs to generate a traget sequence, meaning model is optimized for generating output

TIP : Encoder-decoder models or sequence-to-sequence models: Good for generative tasks that require an input, such as translation or summarization.
Encoder-only models: Good for tasks that require understanding of the input, such as sentence classification and named entity recognition.
Decoder-only models: Good for generative tasks such as text generation.

Transformer models are made on attention layers, this will tell the model to pay attantion to certain words when it is passed in input
The same concept applies to any task associated with natural language: a word by itself has a meaning, but that meaning is deeply affected by the context, 
which can be any other word (or words) before or after the word being studied.

In the encoder, the attention layers can use all the words in a sentence 
The decoder, however, works sequentially and can only pay attention to the words in the sentence that it has already translated

So to speed things up, decoder is fed whole traget , but it is not allowed to use future words
Attention Mask can also be used in encoder/decoder to prevent the model from paying attention to some special words

Owing to its flexible architecture, most models are a variant of an encoder, a decoder, or an encoder-decoder structure.

How language models work
Languange model work by being trained to predict the probabilty of a word given in the context of surrounding words

there are two main approaches for training a transformer model
1. Masked language Modeling (MLM) : this approach randomly masks some token in input and train the model to predict the orignal token based on surrounding
    this will make model learn bidirectional before and after the mask words
2. Casual Language Modeling (CLM) : this approach predicts the next token on all previous tokens in the sequence : from left to predict next token

/***********************************************************************/
Types of language models
Encoder - only models : use bidirectional approach to understand context from both direction
    they are best suited for tasks that require deep understanding of text like classification, named entity and question answering
Decoder - only models: this process text from left to right and are good for text generation tasks, complete setence, write essay, generate Code
Encoder - decoder models : combine both approach, use encoder to understand input and a decoder to generater the output
    they are good in sequence to sequence tasks like translation, summarization and question answering

Text generation involves creating coherent and contextually relevant text based on a prompt or input.
    GPT-2 uses byte pair encoding (BPE) to tokenize words and generate a token embedding.
    The input embeddings are passed through multiple decoder blocks to output some final hidden state
    Within each decoder block, GPT-2 uses a masked self-attention layer which means GPT-2 can’t attend to future tokens
    The output from the decoder is passed to a language modeling head --> linear transformation to convert hidden states into logits
The cross-entropy loss is calculated between the shifted logits and the labels to output the next most likely token.

Text classification involves assigning predefined categories to text documents, such as sentiment analysis, topic classification, or spam detection.
    BERT uses WordPiece tokenization to generate a token embedding of the text
    special [SEP] token is added to differentiate between single sentence and pair of sentences
    special [CLS] token is added to the beginning of every sequence of text. The final output with the [CLS] token is used as the input to the classification head for classification tasks
BERT is pretrained with two objectives: masked language modeling and next-sentence prediction. The input embeddings are passed through multiple encoder layers to output some final hidden states.
The sequence classification head is a linear layer that accepts the final hidden states and performs a linear transformation to convert them into logits. 
    The cross-entropy loss is calculated between the logits and target to find the most likely label.

Token classification involves assigning a label to each token in a sequence, such as in named entity recognition or part-of-speech tagging.
    The token classification head is a linear layer that accepts the final hidden states and performs a linear transformation to convert them into logits.
    The cross-entropy loss is calculated between the logits and each token to find the most likely label.

TIP : Notice how easy it is to use BERT for different tasks once it’s been pretrained. You only need to add a specific head to the pretrained model to manipulate the hidden states into your desired output!

Summarization involves condensing a longer text into a shorter version while preserving its key information and meaning.
    BART encoder accepts a token and positional embedding of the text. it train by corruptin input and reconstruct it with decoder
    corruption technique like text infilling like mask token in btween the word
    The encoder’s output is passed to the decoder. which must predict the masked tokens and any uncorrupted tokens from the encoder’s output.
    The output from the decoder is passed to a language modeling head, which performs a linear transformation to convert the hidden states into logits

Translation involves converting text from one language to another while preserving its meaning
    The model parameters are frozen in this first step, and all the model parameters are trained together in the second step

Speech and audio : Whisper is a encoder-decoder (sequence-to-sequence) transformer pretrained on 680,000 hours of labeled audio data
    the decoder allows Whisper to map the encoders learned speech representations to useful outputs, such as text, without additional fine-tuning
Two main components:
1. An encoder processes the input audio. The raw audio is first converted into a log-Mel spectrogram
    This spectrogram is then passed through a Transformer encoder network
2. A decoder takes the encoded audio representation and autoregressively predicts the corresponding text tokens
Now that Whisper is pretrained, you can use it directly for zero-shot inference or finetune it on your data for improved performance

Automatic speech recognition : leverage its full encoder-decoder structure
    The encoder processes the audio input, and the decoder autoregressively generates the transcript token by token
    When fine-tuning, the model is typically trained using a standard sequence-to-sequence loss (like cross-entropy) to predict the correct text tokens based on the audio input.

Computer vision : which deal with understanding and interpreting visual information from images or videos.
There are two ways to handle this
1. Split an image into a sequence of patches and process them in parallel with a Transformer.
2. Use a modern CNN, like ConvNeXT, which relies on convolutional layers but adopts modern network designs.

Image classification : one of the fundamental computer vision tasks
ViT and ConvNeXT can both be used for image classification; the main difference is that 
    ViT uses an attention mechanism : ViT replaces convolutions entirely with a pure Transformer architecture
    ConvNeXT uses convolutions.

1. An image is split into square non-overlapping patches. each of which gets turned into a vector or patch embedding.
    If you had a 224x224 pixel image, you could split it into 196 16x16 image patches.
    Just like how text is tokenized into words, an image is “tokenized” into a sequence of patches.
2. A learnable embedding - a special [CLS] token - is added to the beginning of the patch embeddings just like BERT
    other output is ignored
3. The last thing to add to the patch and learnable embeddings are the position embeddings because the model doesn’t know how the image patches are ordered.
    Finally, all of the embeddings are passed to the Transformer encoder.
4. The output, specifically only the output with the [CLS] token, is passed to a multilayer perceptron head (MLP)

Encoder Models :
At each stage, the attention layers can access all the words in the initial sentence. These models are often characterized as having “bi-directional” attention, and are often called auto-encoding models.
pretraining revolves around corrupting a sentence and model reconstruct it

Decoder Models :
At each stage, for a given word the attention layers can only access the words positioned before it in the sentence. These models are often called auto-regressive models.
pretraining revolves around predicting the next word in the senctence

Modern Large Languange Models (LLMs) :
most of them use decoder-only architecture
trained in two phases : pretraining, instruction tuning (fine tuning)

Sequence to Sequence Models :
Encoder-decoder models (also called sequence-to-sequence models) use both parts of the Transformer architecture
At each stage, the attention layers of the encoder can access all the words in the initial sentence, 
    whereas the attention layers of the decoder can only access the words positioned before a given word in the input.

Attention mechanisms :
most transformer use full attention like attention matrix is suare, so to avoid bottleneck we have different methods

LSH Attention :
Reformer uses LSH attention
Ex : In softmax (QK^t) only biggest elemnt of matrix are useful
    so for each query q in Q, we consider only the keys k in K that are close to Q
    A hash function is used to determine if q and k are close
    Hash can be a bit random so multiple has function used and then averaged together

Local Attention : 
Longformer uses local attention
Local context is enough to take action for given token, also by stacking attention layers
    so last layer will have enough receptive token in the window allowing to build a representation
    Preselected input token also given to global attention and all this process is symetric
